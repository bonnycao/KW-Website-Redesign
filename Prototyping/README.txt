KEELWORKS WEBSITE 2.0 — LOCAL PREVIEW

1. Extract the ENTIRE ZIP file to a folder (do not preview index.html inside the ZIP).
2. Keep index.html together with the html, css, js, and images folders.
3. Open index.html from the extracted folder in your browser.
4. Click navigation and footer links. Internal pages are in the html folder.

If deploying to a website, upload the entire extracted folder structure, not just index.html.
External links require an internet connection; third-party destinations may change.
